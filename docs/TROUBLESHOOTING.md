# Troubleshooting

- **No devices found**: Verify all devices on same LAN, firewall open for UDP 47822/TCP 47821, multicast not blocked by router.
- **Cannot connect**: Test with diagnostics page; ensure target app running.
- **Transfer fails**: Check disk space, permissions on shared folder (upload/manage).
- **Slow speeds**: Use wired Ethernet; close other traffic; chunk size default 64KB.
- **Windows SmartScreen**: Unsigned build; allow manually.
